Enable bug root cause found:

In templatized_alu_control, if add group is 001, bool is 010, and shift is 100,
the mux_generic is mapping en[2] -> shift, en[1] -> bool, en[0] -> add, which should be reversed.

Simple reversing the order of generation in mux_generic does not work because the mapping itself comes from
group_list in generate_alu.py.

Fix will be found by either changing how the "group" is setup in generate_alu or by changing control_module_template.sv.j2
